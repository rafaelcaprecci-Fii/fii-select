# Padrão de nomes dos documentos

## Formato obrigatório

```txt
TICKER_AAAA-MM_tipo-documento_v1.pdf
```

## Tipos de documento aceitos

- `relatorio-gerencial`
- `informe-mensal`
- `regulamento`
- `fato-relevante`
- `comunicado`
- `material-gestora`

## Exemplos corretos

```txt
JSRE11_2026-06_relatorio-gerencial_v1.pdf
JSRE11_2026-06_informe-mensal_v1.pdf
HGLG11_2026-06_relatorio-gerencial_v1.pdf
XPML11_2026-06_fato-relevante_v1.pdf
```

## Exemplos incorretos

```txt
jsre11 junho relatorio.pdf
JSRE11_06-2026_relatorio.pdf
Relatorio JSRE11.pdf
XPML11_2026_06_informe.pdf
```

## Regra para retificação

Quando um documento for retificado, não substituir o arquivo anterior.

Usar uma nova versão:

```txt
JSRE11_2026-06_informe-mensal_v2.pdf
```

O índice documental deve manter a versão anterior como histórico e marcar a versão mais recente como documento ativo.
